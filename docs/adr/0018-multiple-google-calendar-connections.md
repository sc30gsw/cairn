# 複数アカウントの予定を閲覧し、Google への書き込み先は1つ選ぶ

個人用と仕事用の Google アカウントを持つ所有者は、片方の予定だけでは学習の空き時間を判断できない。所有者が複数のカレンダー接続を同時に持ち、各アカウントの外部予定を実行ボードで確認できるようにする。Cairn の予定・本番日・未達成チェックポイントの期限は、所有者が選ぶ1つのカレンダーへ書き出す。これにより [ADR-0017](./0017-google-calendar-two-way-sync.md) のメインカレンダー固定を変更する。

書き込み先は所有者自身が選ぶ。個人用アカウントに固定せず、Google 側の書き込み権限と所有者による許可を満たす接続先から選べるようにする。接続先を追加しただけで、現在の書き込み先を変更しない。

追加する仕事用などの接続は閲覧専用とする。会議には他の参加者がいるため、Google 側の編集権限の有無にかかわらず、Cairn からその外部予定を変更しない。現在の接続の外部予定の編集機能は維持する。

接続したすべてのアカウントへ Cairn の予定を複製する案は、空き時間の確認という目的に不要な複製と複数の編集元を生むため採らない。追加接続も一律に編集可能にする案は、仕事用の会議を一方的に変更しないという所有者の意図に合わない。

追加アカウントをログイン手段にしない判断は [ADR-0019](./0019-calendar-connections-do-not-grant-sign-in.md) に記録する。書き込み先を切り替えた場合は、Cairn が作った既存の Google 予定を新しい保存先へ移し、古い写しを削除する。Google で作られた外部予定は移動しない。接続解除と移行の詳細は [multiple-google-calendars.md](../specs/multiple-google-calendars.md) に残す。
