# 見送り確認と実行ボードの日付

日ページの見送り操作は Confirm モーダルで確認する。カンバンのドラッグによる状態変更は即実行とする。見送りの取り消しは日ページの専用ボタンから Confirm 付きで行う。実行ボードのカンバンは `search.date` で学習日を選び、チェックポイント列は選択日基準の直近未達を示す。日ページとカンバンは相互リンクで行き来する。

**Considered Options:** 学習量への影響で Confirm を統一する案、表面ごとに Confirm の有無を分ける案（採用）、チェックポイントを常に今日基準にする案。

**Consequences:** 同じ `skip` mutation でも UI によって確認の有無が変わる。過去日のカンバンでは「その日時点」の次のチェックポイントが見える。
